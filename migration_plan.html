Logged Decisions & Rationale
No Local Copies or Clones of Android Skills Rule Rejected

Decision: We explicitly rejected copying or cloning files from the official android/skills repository locally into either pi.dev or nothing.

Rationale: Direct copying or cloning introduces severe update drift. When Google updates the official skills on GitHub, any local setup becomes immediately stale. To keep tools up-to-date automatically, we resolve them dynamically.

Dynamic MCP Server Resolution Rule Approved

Decision: We registered the android-skills MCP server via NPM registry invocation (npx -y android-skills-mcp) in the agent settings.

Rationale: Loads the latest canonical Android guidelines dynamically on-demand, preventing repository bloat, simplifying cross-platform bootstraps, and guaranteeing the developer always uses the latest guidelines without manual intervention.

Removal of Hardcoded default_models Rule Approved

Decision: Dropped the default LLM list block from the configurations, loading only the last selected mindset as the active profile.

Rationale: Prevents model selection redundancy and keeps configuration files lean and clean.

Package-based Installation Model Rule Approved

Decision: Replace platform-specific symlink setups with standard global NPM package installs (e.g. publishing notrace).

Rationale: Avoids complex file path symlinking on Linux vs. macOS, ensures clean upgrades, and makes dotfiles installation lightweight.

Path: bootstrap.sh (Staged blueprint) 
#!/usr/bin/env bash
set -euo pipefail

# 1. Detect OS Platform
OS="$(uname -s)"
case "$OS" in
  Darwin)
    echo "Installing tools via Homebrew..."
    brew install node tmux git gh go
    ;;
  Linux)
    echo "Installing tools via apt-get..."
    if command -v apt-get &>/dev/null; then
      sudo apt-get update && sudo apt-get install -y nodejs npm tmux git github-cli golang
    fi
    ;;
esac

# 2. Install Pi Coding Agent and extensions from NPM
echo "Installing packages from NPM..."
npm install -g @mariozechner/pi-coding-agent
npm install -g notrace noleaks

# 3. Mount configurations
mkdir -p "$HOME/.pi/agent"
cp settings.json "$HOME/.pi/agent/settings.json"
echo "Bootstrap complete! 🎉"

Path: dotfiles/shell_integration.sh (Staged wrapper loader) 
pi() {
  local NOTHING_DIR
  NOTHING_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
  
  local MINDSETS_JSON="$NOTHING_DIR/mindsets.json"
  export PI_MINDSET=""
  
  local ARGS=()
  local EXTRA_SKILLS=()
  local EXTRA_EXTENSIONS=()
  
  # Parse Custom Mindset Flags dynamically
  while [[ $# -gt 0 ]]; do
    case "$1" in
      --android|--pm|--dev|--rpiv|--meta)
        local flag_name="${1#--}"
        export PI_MINDSET="$flag_name"
        
        # Extract skills from JSON
        local skills=$(node -e "const d=require('$MINDSETS_JSON'); console.log(d.mindsets['$flag_name'].skills.join(' '))")
        for sk in $skills; do
          EXTRA_SKILLS+=("--skill" "$NOTHING_DIR/packages/$sk")
        done
        
        # Extract extensions from JSON
        local extensions=$(node -e "const d=require('$MINDSETS_JSON'); console.log(d.mindsets['$flag_name'].extensions.join(' '))")
        for ext in $extensions; do
          EXTRA_EXTENSIONS+=("--extension" "$NOTHING_DIR/packages/$ext")
        done
        shift
        ;;
      *) ARGS+=("$1"); shift ;;
    esac
  done

  command pi "${EXTRA_SKILLS[@]}" "${EXTRA_EXTENSIONS[@]}" "${ARGS[@]}"
}

Path: .github/workflows/sync-upstream-skills.yml (Staged blueprint) 
name: Sync Upstream Android Skills
on:
  schedule:
    # Run weekly (Sundays at midnight)
    - cron: '0 0 * * 0'
  workflow_dispatch: # Allow manual triggering

jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout nothing repository
        uses: actions/checkout@v4

      - name: Clone official android/skills repository
        run: |
          git clone --depth 1 https://github.com/android/skills.git upstream_skills

      - name: Synchronize guidelines to packages/android/
        run: |
          mkdir -p packages/android
          # Synchronize files while retaining local exclusions or customizations
          rsync -av --delete --exclude='.git' upstream_skills/ packages/android/
          rm -rf upstream_skills

      - name: Create reviewable Pull Request if modifications exist
        uses: peter-evans/create-pull-request@v6
        with:
          token: ${{ secrets.GITHUB_TOKEN }}
          commit-message: "chore(android): sync guidelines with official upstream repo"
          title: "🔄 Update Official Android Guidelines"
          body: |
            This automated Pull Request syncs the local `packages/android/` guidelines
            with the canonical upstream repository: https://github.com/android/skills.
            Please review the diff before merging to check for rules and prompts updates.
          branch: android-skills-sync
          delete-branch: true
