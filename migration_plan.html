📦 Phase 1: NPM Packaging for notrace

Preparing and publishing the local HTML Trace Viewer as a global NPM package.

Initialize standalone package directory
Create a separate workspace folder `packages/notrace/` with `src/index.ts` containing the trace code.
Create package.json metadata
Set entry points and add `@mariozechner/pi-coding-agent` to peerDependencies.
"name": "notrace", "main": "dist/index.js", "peerDependencies": { "@mariozechner/pi-coding-agent": ">=0.70.0" }
Initialize Changesets release automation
Install `@changesets/cli` in the root workspace and run `npx changeset init` to set up automated versioning and changelogs.
npm install -D @changesets/cli npx changeset init
Publish to NPM registry
Use `npx changeset version` and `npx changeset publish` to bump package versions and publish to NPM automatically.

Setting up your dotfiles, shell configs, and unified cross-platform bootstrap script.

Write OS-detecting bootstrap.sh
A unified installer script that handles platform discovery (macOS vs Linux) and installs core packages.
OS="$(uname -s)" case "$OS" in Darwin) brew install node tmux git gh go ;; Linux) sudo apt-get install -y nodejs npm tmux git github-cli golang ;; esac
Configure settings.json template
Setup settings template containing your default provider. Keep `"packages": []` empty by default to prevent global autoloading.
Add shell config integrations
Include shell loaders that source `.pi-secrets/.env` and initialize path wrappers on startup.
Create declarative mindsets.json
