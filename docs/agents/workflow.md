# Agent Workflow Context

Durable workflow context for pi.dev. Keep this concise and update via `/update-docs` when workflow rules change.

- Task artifacts live in `.workflow/tasks/[source-id]/WORK.md` and are not committed.
- Use explicit namespaces: `jira:`, `github:`, `gitlab:`, or `local:`.
- Role hats are `--pm`, `--dev`, and `--rpiv`; platform hats such as `--android` are modifiers.
